# Clankistorian

(clanker historian.)
A tool that watches your git repository and generates "so-so" commit messages while you work using a local LLM.

## Advice on using Clankistorian

* Please don't push its commits publicly. They won't be any good.
* Clankistorian was built to solve a common problem: Everyone knows they're supposed to make atomic commits as they work, but no one wants to context-switch.
